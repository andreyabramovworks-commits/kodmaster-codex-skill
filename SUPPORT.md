# Support

- Usage questions and reproducible bugs: https://github.com/andreyabramovworks-commits/Kodmaster---skill-for-codex/issues
- Feature discussions: https://github.com/andreyabramovworks-commits/Kodmaster---skill-for-codex/discussions
- Sensitive security reports: use the repository's private security advisory.

Include the KodMaster version, host product, expected behavior, actual behavior and a minimal safe reproduction. Never post API keys, passwords or private source code in a public issue.
