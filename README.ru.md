# KodMaster v4 — автономный аудит и разработка для Codex

KodMaster понимает обычный текст, сам выбирает нужную команду и глубину, проверяет всё приложение, находит первопричины, исправляет баги и отдельно аудирует интерфейс. Заимствованные методики полностью встроены: пользователю не нужны другие скиллы.

## Что умеет

- технический аудит кода, архитектуры, API, БД, безопасности, зависимостей, производительности, тестов и CI/CD;
- отдельный UI/UX/a11y-аудит со сценариями, состояниями, responsive и текстами;
- React/Next.js, PostgreSQL и Supabase-профили;
- поиск → воспроизведение → первопричина → исправление → регрессионный тест → приёмка diff;
- проверка грамматики, перевод RU→EN, редактирование и стилизация текстов;
- Fast, Adaptive и Deep без лишней траты токенов.

## Самый простой запуск

```text
Используй KodMaster. Проверь всё приложение, найди баги и нерабочие сценарии. Deep. Пока ничего не исправляй.
```

Или:

```text
Проверь интерфейс регистрации на компьютере и телефоне, найди проблемы UX, доступности и текстов.
```

Команды `/kodplan`, `/kodaudit`, `/uiaudit`, `/apply`, `/kodsend`, `/fast`, `/deep` и `/kodhelp` остаются для точного управления. Старая `/audit` работает как скрытый алиас Discovery внутри `/kodaudit`.

## Установка

Для Codex скачайте `kodmaster-v4-codex-windows.zip`, распакуйте и дважды нажмите `install-kodmaster.cmd`. Для веб‑версии загрузите `kodmaster-v4-skill.zip` через **Plugins → Skills → Create → Upload from computer**.

Полная инструкция для новичка: [INSTALL.md](INSTALL.md). Архитектура и методики: [skills/kodmaster/docs/DOCUMENTATION.md](skills/kodmaster/docs/DOCUMENTATION.md).
