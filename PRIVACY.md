# Privacy Policy

Effective date: 2026-08-21

KodMaster is an instruction-only, open-source skill. It does not operate a server, create user accounts, collect analytics, sell data, or independently transmit personal data.

When a user runs KodMaster, the hosting product (for example ChatGPT or Codex) and any tools the user enables may process prompts, repository files, logs or screenshots under their own terms and privacy settings. KodMaster instructs the agent to minimize access, redact secrets and personal data in reports, and avoid unnecessary external transmission.

Users are responsible for having permission to inspect the code, systems and data they place in scope. Do not include credentials or sensitive personal data in public issues.

Privacy questions: open a private GitHub security advisory or use the support channel in [SUPPORT.md](SUPPORT.md).
