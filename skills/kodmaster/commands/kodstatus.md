# /kodstatus

Назначение: кратко показать, где сейчас находится текущая Codex-задача.

Выводить только известные факты:
- Task ID и краткая цель;
- текущая ветка;
- этап: PLANNING | READY | CODEX | TESTING | AUDIT | REWORK | MERGING | DEPLOYING | DONE | BLOCKED;
- последний подтверждённый commit SHA, если известен;
- результат последнего аудита;
- состояние production deployment;
- одно следующее действие, если оно требуется.

Не придумывать фоновые статусы и не писать, что Codex или deploy выполняются, если нет фактического подтверждения.
