# `/kodplan` — план без изменений

Срабатывает также по смыслу: «составь план», «сначала разберись», «ничего пока не меняй».

1. Изучить доступный контекст read-only.
2. Выбрать Fast/Adaptive/Deep.
3. Выполнить `references/rule-router.md` и перечислить применимые rule packs.
4. Зафиксировать цель, scope/non-goals, assumptions, риск и неизвестные.
5. Для бага включить воспроизведение/root cause; UI — runtime/screenshot evidence; БД — migration/data risk; Codex — delivery path.
6. Составить этапы, acceptance criteria, проверки и stop conditions.
7. Задать только блокирующие вопросы. Иначе зафиксировать безопасные предположения.
8. Остановиться: файлы не изменены.

Формат:

```text
Маршрут: ...
Режим: Fast | Adaptive | Deep
Риск: низкий | средний | высокий
Rule packs: ...
Scope / не трогаем: ...
Предположения и неизвестные: ...
План: ...
Доказательства и проверки: ...
Stop conditions: ...
Никакие файлы не изменены.
```
