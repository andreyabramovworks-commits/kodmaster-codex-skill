# `/kodplan` — план без изменений

Срабатывает также по смыслу: «составь план», «сначала разберись», «ничего пока не меняй».

1. Изучить доступные файлы/контекст read-only.
2. Выбрать Fast/Deep/Adaptive и применимые профили, не загружая лишние.
3. Зафиксировать цель, scope, non-goals, assumptions, риск и неизвестные.
4. Для бага включить этап воспроизведения и root cause; для UI — screenshot/runtime evidence; для БД — migration/rollback; для текста — нужный режим редактирования.
5. Составить этапы, критерии готовности, проверки и stop conditions.
6. Задать только блокирующие вопросы. Иначе указать безопасные предположения.
7. Остановиться: никакие файлы не изменены.

Формат:

```text
Маршрут: ...
Режим: Fast | Adaptive | Deep
Риск: низкий | средний | высокий
Scope / не трогаем: ...
Предположения и неизвестные: ...
План: ...
Доказательства и проверки: ...
Stop conditions: ...
Никакие файлы не изменены.
```
