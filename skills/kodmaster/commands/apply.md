# `/apply` — выполнить согласованную работу

Срабатывает по смыслу «исправь», «почини», «реализуй», если scope понятен.

1. Проверить актуальность плана и dirty worktree.
2. Выполнить Rule Router и загрузить все обязательные packs до изменения.
3. Для бага подтвердить root cause и по возможности получить regression reproduction/test.
4. Внести минимальное изменение в точке первопричины, сохраняя conventions проекта.
5. Не делать несвязанный cleanup.
6. Если во время работы найден новый слой системы — повторить Rule Router до его изменения.
7. Выполнить focused checks и расширить по риску.
8. Variant sweep и Acceptance итогового diff.
9. Сообщить changed files, evidence и residual risks.

Commit/push/merge/deploy автоматически не разрешены. Существенное изменение scope требует обновить план.
