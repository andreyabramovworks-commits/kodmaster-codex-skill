# `/apply` — выполнить согласованную работу

Срабатывает также по смыслу «исправь», «почини», «реализуй», если scope понятен. Для зарегистрированного бага сначала прочитать `references/debugging-and-tests.md` и подтвердить первопричину.

1. Проверить актуальность плана и dirty worktree.
2. Создать минимальное воспроизведение/регрессионный тест для бага.
3. Внести минимальное изменение в точке первопричины, сохранив conventions проекта.
4. Не делать несвязанный cleanup.
5. Выполнить focused checks и расширить их по риску.
6. Провести variant sweep и Acceptance по итоговому diff.
7. Сообщить изменённые файлы, доказательства и остаточные риски.

Commit, push, merge и deploy не разрешены автоматически. Существенное изменение scope требует обновить план.
