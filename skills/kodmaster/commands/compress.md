# /compress

## Назначение

Интеллектуально сжать активную историю, сохранив всё необходимое для продолжения работы.

## Обязательно сохранить

- цель задачи;
- согласованный scope;
- принятые решения и причины;
- архитектурные ограничения;
- обнаруженные ошибки и причины;
- изменённые файлы;
- результаты проверок;
- незавершённые действия;
- следующие шаги.

## Можно свернуть

- повторяющиеся логи;
- промежуточные неудачные поиски;
- дублирующие объяснения;
- устаревшие гипотезы, если сохранён итог их проверки.

Не удалять файлы проекта. Не изменять `.codex/decisions.md` без нового решения.
