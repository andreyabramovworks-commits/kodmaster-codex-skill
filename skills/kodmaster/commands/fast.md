# `/fast` — сфокусированный режим

Fast ограничивает область кода, но **не отменяет обязательные правила**.

1. Выполнить Rule Router.
2. Читать целевой scope, direct imports/callers/callees/contracts.
3. Запускать самые дешёвые достаточные проверки.
4. Обычно использовать 1–2 reference profiles, но не считать это жёстким лимитом.
5. Если найден системный риск или новый слой, подключить его rule pack и при необходимости перейти к Adaptive. Сообщить об эскалации кратко.

Fast запрещено использовать как основание для вывода «всё приложение проверено».
