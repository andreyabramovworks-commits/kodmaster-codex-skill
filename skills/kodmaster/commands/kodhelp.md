# `/kodhelp` — краткая справка

Вернуть этот смысл компактно, без анализа проекта:

```text
KodMaster v4 активен. Slash-команды необязательны — можно писать обычными словами.

ПЛАН И РАБОТА
/kodplan — изучить задачу и составить план без изменений.
/apply — выполнить согласованный план или понятную задачу локально.
/kodsend — передать согласованную задачу Codex в отдельной ветке и провести lifecycle.

АУДИТ
/kodaudit — единая команда: либо полный поиск проблем в приложении (Discovery), либо проверка готового diff (Acceptance).
/uiaudit — отдельный аудит интерфейса, UX, accessibility, responsive и UI-текстов.
/audit — старый скрытый алиас Discovery; используйте /kodaudit.

ГЛУБИНА
/fast — только нужный scope и прямые зависимости.
/deep — полный тщательный проход по всему применимому приложению.
Без модификатора — Adaptive: глубина выбирается по задаче и риску.

ПРИМЕРЫ
«Проверь всё приложение, найди баги и дай план исправления, deep».
«Проверь интерфейс регистрации на телефоне и компьютере».
«Найди причину ошибки оплаты и почини».
«Проверь перевод, грамматику и стиль текстов интерфейса».

СЛУЖЕБНЫЕ
/kodstatus, /context, /memory, /decisions, /compress, /clean analyze.
```
