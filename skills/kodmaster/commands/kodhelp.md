# `/kodhelp` — краткая справка

Вернуть этот смысл компактно, без анализа проекта:

```text
KodMaster v4.1 активен. Slash-команды необязательны — можно писать обычными словами.

ПЛАНИРОВАНИЕ
/kodplan — изучить задачу и составить план без изменений.
Можно сказать: «сделай план», «сначала разберись», «ничего пока не меняй».

ВЫПОЛНЕНИЕ
/apply — выполнить согласованный план или понятную задачу локально.
Можно сказать: «исправь», «почини», «реализуй план», «найди причину и исправь».

CODEX / АВТОМАТИЧЕСКИЙ LIFECYCLE
/kodsend — передать согласованную задачу Codex в отдельной ветке, проверить результат и провести разрешённый lifecycle.
Можно сказать: «отправляй в Codex», «поставь задачу Codex», «запускай в отдельной ветке».

АУДИТ
/kodaudit — поиск проблем (Discovery) или проверка готового diff/Codex-результата (Acceptance).
Можно сказать: «проверь приложение», «найди баги», «проверь код», «проверь, что Codex сделал», «можно ли сливать?».
/audit — старый скрытый алиас Discovery; используйте /kodaudit.

UI / UX
/uiaudit — аудит интерфейса, responsive, accessibility, UI-текстов и UI-архитектуры.
Можно сказать: «проверь интерфейс», «проверь мобильную версию», «сделай UI-аудит», «проверь UX и accessibility».

ГЛУБИНА
/fast — сфокусированный анализ нужной области и прямых зависимостей.
Можно сказать: «быстро проверь только это», «не сканируй весь проект».
/deep — максимально полный проход по всем применимым частям приложения.
Можно сказать: «проверь максимально тщательно», «сделай глубокий аудит», «проверь всё приложение».
Без модификатора используется Adaptive — глубина выбирается по риску и доказательствам.

ТЕКСТЫ
Можно сказать: «проверь грамматику», «переведи RU→EN», «улучши стиль текста», «проверь тексты интерфейса».

СЛУЖЕБНЫЕ
/kodstatus — текущая задача/ветка/этап.
/context — состояние контекста.
/memory — проектная память.
/decisions — архитектурные решения.
/compress — сжать контекст без потери решений.
/clean analyze — показать кандидатов на удаление.
/clean apply 1,3 — удалить только явно выбранные пункты.

ПРИМЕРЫ
«Сделай план исправления авторизации, ничего пока не меняй».
«Проверь всё приложение и найди подтверждённые баги, deep».
«Проверь интерфейс регистрации на телефоне и компьютере».
«Найди причину ошибки оплаты и почини».
«Проверь, что Codex сделал, можно ли сливать».
```
