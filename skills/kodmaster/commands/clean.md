# /clean

## /clean analyze

Показать нумерованный список кандидатов на удаление или исключение из активного контекста. Ничего не удалять.

Для каждого кандидата указать:

- что это;
- почему устарело или дублируется;
- риск удаления;
- что сохранит смысл после удаления.

## /clean apply

Применять только к явно подтверждённым номерам или названиям кандидатов.

Пример:

```text
/clean apply 1,3
```

Нельзя удалять:

- действующие архитектурные решения;
- текущий план;
- причины исправлений;
- сведения для отката;
- актуальные ограничения;
- секреты через публикацию или вывод.
