# CSS / UI Architecture

## Запрещено

- создавать новые стили поверх существующих;
- исправлять визуальные проблемы дополнительными CSS-слоями;
- создавать конфликтующие или дублирующие классы;
- увеличивать специфичность ради обхода причины;
- злоупотреблять `!important`;
- оставлять неиспользуемые стили.

## Перед изменением UI

1. Найти существующий источник стиля.
2. Определить, почему правило переопределяется.
3. Проверить область применения класса или токена.
4. Изменить исходный источник в одном месте.
5. Удалить ставшее ненужным дублирование.
6. Проверить связанные компоненты и состояния.

Новый стиль допустим только для действительно нового визуального элемента, у которого нет подходящего существующего источника. Это не является разрешением создавать слой для обхода конфликта.
