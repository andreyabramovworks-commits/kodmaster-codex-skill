# Context Management

- Не удалять контекст автоматически.
- Операции `/compress` и `/clean` выполняются только по явной команде.
- Сначала анализ, затем применение.
- Сохранять архитектурные решения, ограничения, причины ошибок и следующие шаги.
- В `Fast` не загружать весь репозиторий без необходимости.
- В `Deep` расширять контекст постепенно, следуя зависимостям и архитектуре.
- Не хранить большие повторяющиеся логи, если сохранены релевантные фрагменты и вывод.
- Не считать project memory заменой исходному коду или документации.
