# Database and Integrations

- Изменения PostgreSQL выполнять только через Alembic.
- Не редактировать production-схему вручную.
- Миграции должны иметь понятный upgrade и безопасный downgrade, если проект это поддерживает.
- Проверять обратную совместимость при поэтапном деплое.
- Bitrix24 и аналогичные внешние интеграции вызывать только через backend API.
- Не размещать секреты интеграций во frontend.
- Не менять формат внешнего API без анализа потребителей.
