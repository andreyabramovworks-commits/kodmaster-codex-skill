# Security

- Запрещены секреты, токены, cookies, пароли и приватные ключи в Git.
- Не выводить секреты из HAR и логов в ответе.
- Не ослаблять авторизацию, валидацию или проверку ролей ради исправления симптома.
- Для пользовательского ввода проверять валидацию и экранирование по контексту.
- Не выполнять разрушительные команды без отдельного подтверждения.
- При обнаружении секрета сообщить о типе проблемы без повторения значения и рекомендовать ротацию.
