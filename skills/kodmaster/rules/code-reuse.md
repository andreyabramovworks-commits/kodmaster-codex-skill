# Code Reuse

Перед созданием новой логики:

1. Найти существующую реализацию.
2. Проверить её точки использования.
3. Определить, можно ли переиспользовать или расширить её.
4. Предпочитать параметры, композицию, небольшие сервисы и общие функции.
5. Создавать новую реализацию только при различной ответственности или несовместимых требованиях.

Запрещено копировать блок кода и изменять его локально без обоснования.
