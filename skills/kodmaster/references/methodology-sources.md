# Methodology Sources

Использовать внешние методики как ориентиры, не как замену фактическому анализу проекта.

Основные UI-ориентиры: Apple Human Interface Guidelines, Material Design, Nielsen Norman usability heuristics, Refactoring UI. Security: OWASP/CWE/STRIDE применяются только к реальным потокам и доказательствам. Accessibility: WCAG-ориентиры не дают права заявлять compliance без достаточного покрытия.

Если заимствованная методика влияет на вывод, отделять её от project-specific evidence.
