# Источники методик

KodMaster v4 автономен: эти навыки не требуются при установке. Методики были адаптированы, сокращены и объединены под единый risk-driven workflow.

- Khasky, **Awesome Agent Skills**: architecture, bug-fix, code review/cleanup/standards, API, DB, dependencies, errors, logging, performance, root-cause, security/leak, tests, accessibility, SEO и работа с текстом — https://github.com/khasky/awesome-agent-skills
- Vercel Labs, **Agent Skills**: React/Next.js performance, composition и view transitions — https://github.com/vercel-labs/agent-skills
- Vercel Labs, **Web Interface Guidelines**: web UI review checklist — https://github.com/vercel-labs/web-interface-guidelines
- Supabase, **Postgres Best Practices**: query, schema, RLS, locking, connection and operational practices — https://github.com/supabase/supabase/tree/master/apps/docs/content/troubleshooting
- OpenAI, **Agent Skills standard and Codex documentation**: packaging, discovery and installation model — https://developers.openai.com/codex/skills

Лицензионные уведомления находятся в корне репозитория в `THIRD_PARTY_NOTICES.md`. Не заявлять, что авторы источников одобряют KodMaster.
