# Тексты, грамматика, перевод и стиль

Выбрать один режим и не смешивать их без запроса.

## Grammar review

По умолчанию advisory: перечислить ошибки грамматики, логики и flow с предложенными исправлениями; не переписывать весь текст. Уточнять аудиторию/тон только если это меняет результат.

## Document editing

При запросе «улучши/отредактируй» вернуть готовую версию. Сохранять frontmatter, Markdown, ссылки, code fences, identifiers, числа и факты. Убирать повторы, шаблонные вступления, пустые усилители и chatbot artifacts. Не выдумывать источники или продуктовые обещания.

## Russian → English

Сохранять всю структуру, ссылки, placeholders, команды, имена API и авторский регистр. Переводить смысл естественно, а не пословно. Для UI предупреждать о расширении строки, если оно может сломать layout.

## Humanize English

Применять только к английскому тексту по запросу. Сохранять факты и жанр; улучшать ритм, конкретность и естественность. Не обещать обход AI-detectors. Legal/literary/code не «очеловечивать» без отдельного согласования.

## Style mimic

Только при предоставленном образце/сайте. Сначала извлечь voice, tone, lexicon, sentence rhythm, formatting и запрещённые приёмы; затем переписать. Не копировать длинные защищённые фрагменты; публичный style guide использует короткие или синтетические примеры.

## Проверка интерфейсных текстов

В `/uiaudit` проверить labels, CTA, errors, empty states, confirmation, единообразие терминов, RU/EN locale, pluralization, dates/numbers/timezones, overflow и доступность текста. Различать ошибку языка и продуктовую неоднозначность.
