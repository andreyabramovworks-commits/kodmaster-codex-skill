# Тексты, грамматика, перевод и стиль

Сохранено как полноценная возможность KodMaster по решению пользователя.

- Grammar review: advisory по умолчанию, не переписывать всё без запроса.
- Document editing: при «улучши/отредактируй» вернуть готовую версию, сохраняя факты, Markdown, links, identifiers и structure.
- RU → EN: сохранять placeholders/API names/commands/formatting, переводить естественно.
- Humanize English: только по запросу, без обещаний обхода AI-detectors.
- Style mimic: при наличии образца извлечь tone/lexicon/rhythm/formatting и переписать без копирования длинных защищённых фрагментов.
- UI copy: labels, CTA, errors, empty/confirmation states, terminology, locale/pluralization/dates/numbers/timezones и overflow.
